ScaleTrack is a local-first iPhone weight-tracking app I built and published on the App Store. It helps people log their weight, set goals, view progress trends, attach progress photos, and export their data without requiring an account. I built it with SwiftUI and SwiftData, with optional Vision OCR for photo-based entries and HealthKit syncing for users who want to connect their existing health data.
